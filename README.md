# NBRL's Official Website
Since NBRL is organized horizontally, all members are equally welcome to contribute to our website!
Below are the details necessary for doing so.
## Maintenance
- Update the [visual schedule](assets/schedule.png) **monthly**
- Update the featured event after the current event passes
    - If there *is* an upcoming event
        - Update the [Featured Event page](featured-event.html) with all relevant event details
        - Update the link in the "UPCOMING EVENT" box on the [Home Page](index.html) to reflect the event's name and/or date
            -Ensure the link points towards the [Featured Event page](featured-event.html)
    - If there is *not* an upcoming event
        - Update the link in the "UPCOMING EVENT" box on the [Home Page](index.html) to display something analogous to "No upcoming events. Help us change that!"
            -Ensure the link points towards the ["Suggest An Event" page](suggest-event.html)
- Update the indexes for [Zine Locations](zines.html) and [Projects](projects.html) as needed
